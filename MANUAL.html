1. 申込URLにアクセスする

申込はすべて 1つのウェブページ から行います。ログイン用パスワードはありません。URLにアクセスするだけで始められます。

1-1. アクセス方法

  • 説明会で配布された QRコード をスマホで読み取る
  • 後日、学校から届くメール内のリンクをタップ／クリック
  • PCのブラウザにURLを直接入力 (Chrome / Edge / Safari いずれも対応)
スマホでもPCでもOK
画面の大きさに合わせて自動でレイアウトが切り替わります。スマートフォンで途中まで入力 → PCで続きを入力、というように 同じメールアドレス でログインすれば続きから作業できます（自動保存）。

★ 割引制度のご案内

サマースクールでは、コマ数・きょうだい・補習校／AS・お友達 の4種類の割引をご用意しています。すべての割引はシステムが自動で計算します。

NEW 2026

👫 お友達割引

お友達と 同じコマ を受講する場合、その対象コマのみ10%引きになります。

▷ 申込書（タブ③）の各講座・プレ講習コマの下に表示される黄色のチェックボックスにチェック
▷ お友達のお名前を記入欄に入力（必須）
▷ 複数のコマで別々のお友達を申請することも可能です

※「該当コマのみ」とは、お友達と一緒のコマだけが10%引きになる、という意味です。同じ講座でも他のコマは通常料金です。

① コマ数割引

受講するコマ数が多いほどお得 (1講座 = 5コマ換算 / プレ講習1コマ = 1コマ)
コマ数割引率
10〜14コマ10%引き
15〜19コマ20%引き
20コマ以上30%引き

② きょうだい割引

2人目以降のお子様が割引対象
  • 2人目： 20%引き
  • 3人目以降： 30%引き

※全生徒の割引前合計を比較し、金額が高い生徒から優先で「1人目」扱いとなります（自動計算）。

③ 補習校・AS生割引

対象生徒は10%引き

生徒登録時に「補習校・AS生」のチェックを入れてください。ウェイティング登録の生徒も対象です。

割引の組み合わせについて
上記の割引は条件を満たせば 重ねて適用されます。タブ③「申込・請求書」で、最終的な割引適用後の金額をご確認いただけます。

3. 講座を選ぶ（タブ「① 講座を選ぶ」）

このタブは「生徒登録 → 講座選択 → プレ講習選択」の順で進めていきます。きょうだいでまとめて申し込むこともできます。

3-1. 生徒を登録する

  1. 画面上の ＋ 生徒を追加 ボタンを押す
  2. 氏名・学年・対象区分（小学生／中学生／高校生 など）を入力
  3. 補習校または現地校アフタースクール（AS）に通っているお子様は、「補習校・AS生割引」のチェックを入れる
  4. 2人目以降を追加すると、姓は1人目から自動で引き継がれます（必要なら変更可）

※生徒の削除は、生徒カード右上のメニューから行えます。

📷 スクリーンショット 生徒追加フォーム（補習校・AS生のチェックボックスが見える状態）

3-2. 講座を選ぶ

  • 画面上部の フィルター（ターム・タイプ・先生・キーワード）で講座を絞り込めます
  • 講座カードをクリック／タップで選択。もう一度タップで解除
  • 同じ時間帯に2つ以上の講座を選ぶと、警告メッセージが表示されます
  • ZOOM受講・録画受講を希望される場合は、講座カード内のチェックを入れる
  • 個別講座を選んだ場合は、希望科目を記入する欄が出てきます

残席表示の見方

緑：余裕あり   オレンジ：残りわずか   赤：満席に近い   グレー：満席（ウェイティング受付）

3-3. プレ講習を選ぶ

プレ講習は カレンダー形式で表示されます。日付ごと・時間帯ごとにコマを選択してください。平日と日曜では時間帯が異なります（平日は夕方中心、日曜は午前中心）。

3. 講座を選ぶ（つづき）

3-4. きょうだいがいる場合の便利機能

📋 「コピー」ボタンで時短
生徒カードの上部にある 📋 コピー ボタンを押すと、他の生徒が選んだ講座をそのまま取り込むことができます。
※以下の条件にあたる講座は、自動でスキップされます。
  • すでにその生徒が同じ時間帯に別の講座を選んでいる
  • その生徒の対象学年と合わない講座
  • 満席で選択できない講座

3-5. 満員講座のウェイティング登録

満員（グレー表示）の講座でも、ウェイティング登録が可能です。空きが出た場合に学校からご連絡します。ウェイティング登録は申込書送信時に同時に確定されます。

4. 時間割を確認する（タブ「② 時間割」）

選んだ講座が時間割の形で一覧表示されます。重複や抜けがないか、ここで最終確認します。

4-1. 表示の見方

  • 横軸：曜日／日付　縦軸：時間帯
  • 講座は色付きのブロックで表示されます
  • きょうだいごとに 色分けされます

色分け例： 青 1人目 ピンク 2人目 緑 3人目 橙 4人目 紫 5人目 黄 6人目

4-2. 「全員」と「個別」の切り替え

  • 全員：きょうだい全員の時間割を1枚に重ねて表示。送迎の計画を立てるときに便利
  • 個別：1人ずつの時間割を表示。本人用の控えとして印刷するときに

4-3. 印刷／PDF保存

画面右上の 🖨 印刷 ボタンから印刷できます。プリンタ選択画面で「PDFとして保存」を選べば、PDFファイルとしても保存できます。

📷 スクリーンショット 時間割「全員」表示できょうだい3人分が色分けされている状態
この段階で最終確認を
時間の重複・送迎しづらいスケジュール・受講方法（対面／ZOOM／録画）の選択ミスは、ここで気付きやすくなります。問題があればタブ「①」に戻って修正してください。

11. よくあるご質問（FAQ）

スマートフォンでも使えますか？
はい、スマホ・タブレット・PCすべてに対応しています。画面サイズに合わせて自動でレイアウトが変わります。
きょうだいは同じ申込画面でまとめて申し込めますか？
はい、「＋ 生徒を追加」ボタンで何人でも登録できます。同じ申込書で送信すれば、きょうだい割引も自動適用されます。
途中で中断しても保存されますか？
入力内容は自動で保存されます。ブラウザを閉じても、後で同じURLにアクセスすれば続きから再開できます。
申込後に講座を追加・変更したい
マイページの「変更・キャンセル問い合わせ」フォームからご連絡ください。学校で内容を確認し、対応いたします。
確認メールが届きません
迷惑メールフォルダをまずご確認ください。それでも見つからない場合は、メールアドレスの入力ミスの可能性があります。お電話（248-349-5234）でお問い合わせください。
領収書を紛失してしまった、再発行したい
マイページの「領収書再送依頼」をクリックしてください。同じメールアドレス宛にすぐ再送されます。
パスワードはありますか？
パスワードは不要です。申込URLにアクセスするだけで使えます。マイページは「申込番号 + メールアドレス」でログインします。
PCに不慣れなのですが大丈夫ですか？
大丈夫です。画面の指示通りに進めれば、特別な操作は必要ありません。困ったときは学校までお電話ください。
